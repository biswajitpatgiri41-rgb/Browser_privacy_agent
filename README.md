# privacy-vision-browser-agent

A privacy-preserving browser automation agent that observes, extracts, redacts, and verifies browser context locally before sending only sanitized data to a backend for action planning.

## Architecture Overview

```

┌─────────────────────┐              ┌─────────────────────┐
│  DOM Extraction     │              │  /health            │
│  Local Perception   │              │  /api/v1/agent/plan │
│  PII Detection      │              │  /api/v1/metrics    │
│  Redaction/Tokenize │   HTTPS      │                     │
│  Leakage Verify     │─────────────▶│  LangGraph          │

        │
        ▼
┌─────────────────────┐
│  Local Validation   │
│  Execute Action     │
## Privacy Boundary

The backend **NEVER** receives:
- Raw passwords, authentication secrets, cookies, access tokens, API keys
- Unredacted PII (emails, phones, names, addresses, SSN, credit cards)
- Raw sensitive OCR content
- Unrelated local/browser storage
- Raw screenshots containing sensitive information

The backend **MAY** receive:
- Sanitized DOM/UI structure with anonymous element IDs
- Bounding boxes and safe labels
- Tokens: `[EMAIL]`, `[PASSWORD]`, `[PERSON]`, `[PHONE]`, `[ADDRESS]`, `[SECRET]`, `[CREDIT_CARD]`, `[SSN]`, `[API_KEY]`, `[TOKEN]`, `[FACE_REGION]`, `[OTHER]`
- Optionally sanitized/redacted images
- Task instruction
- Privacy verification metadata

## Protocol Version

All messages use `version: "1.0.0"`.

## Allowed Actions

| Action    | Required Fields                    |
|-----------|------------------------------------|
| `click`   | `element_id`                       |
| `scroll`  | `direction`, `amount`              |
| `select`  | `element_id`, `value`              |
| `navigate`| `url`                              |
| `wait`    | `duration_ms`                      |
| `finish`  | (none)                             |

Element targets use `element_id` (anonymous IDs like `el_a1b2c3d4`) rather than selectors generated by the LLM.

Action confidence is in range `[0, 1]`.

## Request/Response Format

### Agent Request (POST /api/v1/agent/plan)

```json
{
  "version": "1.0.0",
  "request_id": "uuid",
  "session_id": "uuid",
  "task": "Click the login button",
  "context": { "...": "SanitizedContext" },
  "step": 1,
  "allowed_actions": ["click", "scroll", "select", "navigate", "wait", "finish"]
}
```

### Agent Response

```json

  "version": "1.0.0",
  "request_id": "uuid",

## Planner Backends

The planner backend is configurable via `PLANNER_BACKEND`:

1. **api** - External API (OpenAI-compatible) via environment variables
2. **transformers** - Local HuggingFace Transformers (supports LoRA adapters)

Switch backends without modifying orchestration code.

## Quick Start

### Server

```bash
cd server
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Edit .env as needed
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## Configuration

Key environment variables (see `.env.example`):

| Variable | Description | Default |
|----------|-------------|---------|
| `APP_ENV` | Environment (development/production) | production |
| `LOG_LEVEL` | Logging level | info |
| `PLANNER_BACKEND` | api \| transformers | transformers |
| `MODEL_BASE` | HF model ID for transformers backend | Qwen/Qwen2.5-1.5B-Instruct |
| `MODEL_ADAPTER_PATH` | Path to LoRA adapter | (optional) |
| `MODEL_DEVICE` | cpu \| cuda \| auto | auto |
| `API_PROVIDER` | API provider name | openai |
| `API_MODEL` | Model name for API backend | gpt-4o-mini |
| `API_KEY` | API key (from env, never hardcoded) | - |
| `MAX_CONTEXT_ELEMENTS` | Max elements in context | 200 |
| `MAX_REQUEST_BYTES` | Max request payload size | 1048576 |

## Security

- All secrets from environment variables only
- No secrets committed to repository
- Structured logging with request IDs (no sensitive values logged)
- Payload size limits and validation
- Prompt injection detection on untrusted webpage content
- Rate limiting
- Audit logging
